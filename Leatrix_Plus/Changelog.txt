1.60.21 - 20th October 2026
- Added 'Show info cards' ('Interface').  If checked, pointing at something (such as a player, item, spell, buff, quest, etc) and pressing a keybind (you can set it in the configuration panel) will show a color-coded information card.  Pointing at a character will show information such as their average item level, talent choices, buffs and a 3D model of the character with animation slider and gear toggle button.  Pointing at something else will show useful information and a Wowhead link that you can copy with CTRL/C.  This new option replaces the web link keybind which has been removed.
- Added a language dropdown menu ('Settings') so you can choose which language you want the addon to use.
- For 'Enhance minimap' ('Interface'), the new mail indicator will now be better positioned.
- Updated flight times and translations.
